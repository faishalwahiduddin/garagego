GarageGo سجل صيانة السيارة والدراجة النارية على هاتفك. دوّن كل صيانة وكل تعبئة وقود، واعرف موعد تغيير الزيت القادم، وتابع مواعيد الضريبة والاستمارة ورخصة القيادة والتأمين في مكان واحد.

ماذا يمكنك أن تفعل؟
✓ احفظ عدة مركبات في مرآب واحد واختر المركبة النشطة: الاسم، ورقم اللوحة، والشركة المصنّعة، وسنة الصنع، ونوع الوقود، وعداد المسافة، وسعة الزيت
✓ سجل صيانة كامل: التاريخ، وقراءة العداد، والتكلفة، والورشة، وملاحظات قطع الغيار، مع البحث في الصيانات السابقة
✓ جداول صيانة بحسب المسافة (كم) أو الأشهر للزيت والفلاتر والفرامل أو أي قطعة، ويظهر لكل جدول المتبقي ويتحول إلى «قريب» أو «متأخر» داخل التطبيق
✓ عمر زيت المحرك: اعرف المتبقي منه وأعد ضبط العداد بعد التغيير
✓ سجل الوقود: اللترات والسعر والمحطة وتعبئة الخزان كاملًا، ويحسب GarageGo الكيلومترات لكل لتر وأفضل استهلاك ومتوسطه وتكلفة الكيلومتر
✓ درج الوثائق: الضريبة السنوية، وتجديد التسجيل كل ٥ سنوات، ورخصة القيادة، والتأمين، مع الأيام المتبقية وتمييز المنتهي
✓ إجمالي تكلفة التشغيل (الوقود والصيانة والوثائق) وتكلفة الكيلومتر
✓ مؤشر صحة المركبة ينخفض إذا تأخر تغيير الزيت أو انتهت وثيقة
✓ قائمة فحص من ١٠ نقاط (الإطارات والفرامل والزيت والأضواء والبطارية وغيرها) قبل السفر
✓ احفظ نسخة احتياطية كاملة في ملف .grg واستعدها، أو انسخ سجلات الوقود والصيانة بصيغة CSV لجداول البيانات

لماذا GarageGo؟
تطلب أشهر تطبيقات السيارات حسابًا أو تعرض إعلانات أو تقفل المزايا خلف اشتراك. أما GarageGo فبلا حساب، وبلا إعلانات، وبلا أدوات تتبّع، ويعمل دون إنترنت، وتبقى أرقام اللوحات والتكاليف على هاتفك. وسجل الصيانة المرتب يرفع ثقة المشتري عند بيع سيارتك أو دراجتك.

ابدأ بالمركبة التجريبية، ثم أضف مركبتك.
